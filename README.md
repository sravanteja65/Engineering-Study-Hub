# 💻Engineering-Study-Hub
>📚An app where you can find trusted materials.

## Problem🚨❗

There is a Particular Problem that I recorded from Engineering Students. Many are trying to read the books regarding their branch from the library. This is where the problem starts which book they have to study and which will work for their branch, which will clarify their doubt. Many lecturers give the particular reference books to study the concepts but the students are confused at the library which book it is? Where can I find the book? 

To tolerate this problem there is a solution.

---

## Solution💡

### Engineering Study Hub

An app which consists of E-Books regarding the Engineering Stream By the reference of Top Lecturers. Students can choose their Branch and can prepare for exams without any doubt. 

---

## Features✨

* E-Books With Reference from Top Lecturers
* Previous Semisters Question papers
* Practice sheets
* Online Exams
* Previous GATE Papers
* Exams Regarding GATE Syallabus

Students can eventually grow with this solution and features.
